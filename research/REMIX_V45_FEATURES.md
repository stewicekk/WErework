# ReMIX V45-era feature checklist

Use as a regression/feature inspiration list, not as a source of copied implementation:

- reset selected objects' rotation;
- reset selected objects' height;
- safe preview for missing terrain textures;
- clearer yaw/pitch/roll editing;
- text-based Ctrl+C/Ctrl+V object payloads across map/editor instances;
- colored main character shadow handling;
- robust server_attr / atlas generation around DevIL init;
- ground compass and ruler compass;
- `ENABLE_GR2_ANIMATION` option;
- monster-area-info image option;
- optional effect particles in minimap snapshot;
- Python 3 scripting direction;
- robust TGA/DDS header handling.
