# NewSchool UI skill

Treat the application like a professional DCC/map editor: viewport-first, dockable, context-sensitive, dense but readable, keyboard-first, consistent iconography, visible state, undo/redo, search/filter, multi-select and adaptive DPI. Every visible control must execute a real command. Keep destructive actions one step away behind confirmation or undo, not modal spam.
