# Metin2 Formats Skill

Use for format discovery, parser/writer work and compatibility.

Procedure
Locate the real parser/writer.
Trace call sites and data structures.
Inspect real samples.
Record signatures, versions, sizes, offsets, counts and coordinate conventions.
Preserve unknown information.
Add malformed-input and round-trip tests.
Verify deterministic output.

Never infer a format solely from a web description when source/sample evidence exists.
